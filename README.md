# Webtechnologien-Projekt-QK
Unsere Webanwendung soll ein BMI Rechner/Tracker werden.
Er soll die letzte Eingabe von Gewicht, Größe und Alter speichern. Und auch die letzte Ausgabe des BMI-Wertes.
Außerdem soll er die Vergangenen Werte von Gewicht und BMI anhand von einem Kalender/Diagramm (oder etwas ähnlichem) darstellen.
